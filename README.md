# UniversityJavaTasks — каталог автомобилей

Консольное приложение на Java для хранения и обработки списка автомобилей. Можно добавлять автомобили вручную, загружать их из файлов, просматривать каталог, фильтровать по мощности и сортировать по году выпуска.

Проект реализует базовый уровень задания и дополнительный уровень 3: два собственных алгоритма сортировки с обобщениями и полиморфизмом через интерфейс `SortAlgorithm<T>`.

## Требования для запуска

- **JDK 17 или новее**, включая команды `java` и `javac`. В сохранённых настройках IntelliJ IDEA указан JDK 21; при открытии проекта выберите установленный у вас JDK.
- Терминал или IntelliJ IDEA с поддержкой Java и Gradle.
- Интернет при первой сборке для скачивания Gradle и зависимостей. После загрузки зависимостей возможна сборка с параметром `--offline`.

В проект включён **Gradle Wrapper 9.0.0**, поэтому отдельно устанавливать Gradle не нужно. Используйте `gradlew` на macOS/Linux и `gradlew.bat` на Windows.

Зависимости объявлены в `build.gradle.kts` и загружаются из Maven Central:

| Библиотека | Версия | Назначение |
| --- | --- | --- |
| Apache Commons CSV | 1.10.0 | Чтение CSV |
| Jackson Databind | 2.17.2 | Чтение JSON |

Проверьте наличие JDK:

```shell
java -version
javac -version
```

Версия Java для компиляции явно не закреплена в Gradle. Сборка использует JDK, выбранный для Gradle; запускайте скомпилированное приложение на совместимой версии Java.

## Сборка проекта

Откройте терминал в корневой папке проекта — рядом с `build.gradle.kts`, `settings.gradle.kts` и `gradlew`.

**macOS / Linux:**

```shell
./gradlew build
```

**Windows, PowerShell:**

```powershell
.\gradlew.bat build
```

Если на macOS/Linux нет права на выполнение Wrapper, выполните `chmod +x gradlew` и повторите команду.

При успешной сборке Gradle выводит `BUILD SUCCESSFUL`. Скомпилированные классы находятся в `build/classes/java/main`.


## Запуск в IntelliJ IDEA

1. Откройте корневую папку проекта или файл `build.gradle.kts` как Gradle-проект.
2. Дождитесь импорта проекта и загрузки зависимостей.
3. В настройках проекта выберите установленный **JDK 17+**. Для Gradle JVM также укажите подходящий JDK.
4. Откройте `src/main/java/org/example/Main.java`.
5. Запустите метод `main()` средствами IDE.
6. В конфигурации запуска проверьте рабочую папку: это должен быть корень `UniversityJavaTasks`. Тогда относительные пути вида `test_data/cars.csv` будут работать.
7. В консоли запущенного приложения введите номер нужного пункта и нажмите Enter.

Точка входа: `org.example.Main`. Аргументы командной строки не требуются.
После появления меню приложение готово к работе. Для обычного завершения выберите `0`.

## Работа с меню

```text
===== КАТАЛОГ АВТОМОБИЛЕЙ =====
1. Добавить автомобиль вручную
2. Загрузить автомобили из файла
3. Показать все автомобили
4. Отфильтровать автомобили по мощности
5. Отсортировать автомобили по году выпуска
0. Выход
```

После выполнения действия программа снова показывает меню. Нечисловой ввод в числовом поле вызывает сообщение об ошибке и повторный запрос. Неизвестный номер пункта возвращает к выбору действия.

### 1. Добавить автомобиль вручную

Последовательно введите модель, год выпуска и мощность — каждое значение с новой строки.

| Поле | Допустимое значение |
| --- | --- |
| Модель | Непустая строка; пробелы по краям удаляются |
| Год выпуска | Целое число от 1886 до текущего года включительно |
| Мощность | Целое число от 1 до 2300 л.с. включительно |

Текущий год определяется по системной дате компьютера. Ограничения одинаковы для ручного ввода и загрузки из файлов.

Например, после выбора пункта `1` введите:

```text
Kia Sportage
2020
150
```

Если модель, год или мощность не проходят проверку, автомобиль не добавляется и программа возвращается в меню. Для повторной попытки снова выберите `1`.

### 2. Загрузить автомобили из файла

Введите полный или относительный путь к файлу, например:

```text
test_data/cars.csv
```

Относительный путь отсчитывается от рабочей папки приложения. Путь вводится в консоль самой программы **без окружающих кавычек**, в том числе если в нём есть пробелы.

Данные добавляются к уже имеющемуся каталогу. Повторная загрузка того же файла добавляет повторные записи. Если при чтении обнаружена обрабатываемая ошибка, данные из этого файла не добавляются, а существующий каталог сохраняется.

### 3. Показать все автомобили

Выводит модель, год выпуска и мощность каждого автомобиля в порядке добавления. Если каталог пуст, программа сообщает об этом.

Пример представления одного автомобиля:

```text
--------------------
Модель: Kia Sportage
Год выпуска: 2020
Мощность: 150
--------------------
```

### 4. Отфильтровать автомобили по мощности

Введите минимальную мощность. Программа выбирает автомобили с мощностью **не меньше указанной**, сортирует найденные автомобили по году выпуска по возрастанию и выводит результат.

Порог `0` включает все автомобили, отрицательное значение отклоняется. Если подходящих автомобилей нет, выводится соответствующее сообщение.

### 5. Отсортировать автомобили по году выпуска

Сначала выберите алгоритм:

- `1` — сортировка вставками (`InsertionSort`);
- `2` — сортировка выбором (`SelectionSort`).

Затем выберите направление:

- `1` — по возрастанию, от более раннего года к более позднему;
- `2` — по убыванию, от более позднего года к более раннему.

Результат выводится в консоль. Сортировка выполняется на копии списка, поэтому порядок исходного каталога не меняется. При неверном номере алгоритма или направления программа возвращается в меню.

### 0. Выход

Завершает приложение. Каталог хранится в оперативной памяти и после выхода не сохраняется.

## Форматы файлов

**TXT, CSV и JSON поддерживаются для загрузки. Результаты обработки выводятся в консоль. Экспорт или сохранение каталога в файлы в текущей версии не реализованы.**

| Формат | Расширение |
| --- | --- |
| TXT | `.txt` |
| CSV | `.csv` |
| JSON | `.json` |

Формат определяется по расширению пути. Расширения должны быть строчными: например, `.CSV` не распознаётся. Сохраняйте входные файлы в **UTF-8 без BOM**. Числовые значения записывайте целыми числами без пробелов по краям и разделителей разрядов.

### TXT

Один автомобиль — одна строка. Заголовок отсутствует. Порядок полей фиксирован:

```text
модель;мощность;год
```

Пример:

```text
Kia;222;2003
Mazda CX-5;147;2025
```

Разделитель — точка с запятой `;`. В строке должно быть ровно три поля. Пустые строки пропускаются. Кавычки не обрабатываются как средство экранирования, поэтому модель в TXT не должна содержать `;`. При ошибке сообщается номер строки.

### CSV

Первая строка содержит заголовки `model`, `power`, `year`. Разделитель — **точка с запятой**, а не запятая.

```csv
model;power;year
Kia;222;2003
Mazda CX-5;147;2025
```

Названия обязательных столбцов регистрозависимы. Порядок столбцов можно менять: значения считываются по именам заголовков. Число значений в записи должно соответствовать числу столбцов.

Для модели с точкой с запятой используйте двойные кавычки. Двойная кавычка внутри такого поля записывается дважды:

```csv
model;power;year
"Модель; специальная версия";150;2020
"Модель ""Спорт""";200;2021
```

### JSON

Корневой элемент — массив объектов. Каждый объект содержит строковое поле `model` и целочисленные поля `power`, `year`:

```json
[
  {
    "model": "Kia",
    "power": 222,
    "year": 2003
  },
  {
    "model": "Mazda CX-5",
    "power": 147,
    "year": 2025
  }
]
```

Порядок полей произвольный. Числа в кавычках, дробные значения, `null`, пропущенные обязательные поля и числа за пределами Java `int` отклоняются. Дополнительные поля объектов не используются.

Пустой TXT, CSV только с корректной строкой заголовков или JSON-массив `[]` означают загрузку нуля автомобилей.

## Обработка данных и сортировки

В `CarService.findCarsByMinPower()` используется последовательность операций Stream API:

```java
cars.stream()
    .filter(car -> car.getPower() >= minPower)
    .sorted(Comparator.comparingInt(Car::getYear))
    .map(Car::toString)
    .toList();
```

Таким образом, пункт меню `4` демонстрирует фильтрацию, сортировку по одному полю и преобразование объектов в строки через `map()`. Полученные строки выводит `ConsoleApplication`.

Пункт меню `5` использует собственные алгоритмы, реализующие общий интерфейс:

```java
public interface SortAlgorithm<T> {
    void sort(List<T> list, Comparator<T> comparator);
}
```

| Алгоритм | Принцип работы | Временная сложность для списка на основе массива |
| --- | --- | --- |
| `InsertionSort<T>` | Вставляет очередной элемент в нужное место отсортированной части списка | Лучший случай — O(n), средний и худший — O(n²) |
| `SelectionSort<T>` | Находит следующий минимальный по компаратору элемент и переставляет его | O(n²) |

Оба алгоритма принимают тип элементов через `T` и порядок сравнения через `Comparator<T>`. В приложении используется `Comparator.comparingInt(Car::getYear)`; для убывания — его `reversed()`.

`ConsoleApplication` выбирает конкретную реализацию во время работы программы. `CarService` обращается к ней через тип `SortAlgorithm<Car>` и сортирует копию каталога. Порядок автомобилей с одинаковым годом не закреплён как общее правило: сортировка выбором не является стабильной.

| --- | --- |

| `SortAlgorithm<T>` | Общий контракт собственных сортировок |
| `InsertionSort<T>` | Сортировка вставками |
| `SelectionSort<T>` | Сортировка выбором |
